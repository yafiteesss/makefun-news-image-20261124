A program that draws one 1024x1024 image summing up the world's news of Tuesday 24 November 2026: six stories from that day — Nvidia reinstates Jensen Huang, Ukraine sinks a Russian warship off Libya, COP31 ends with no deal, mines hit tankers in the Strait of Hormuz, NATO warns on a space threat, and a factory fire kills 26 in Indonesia. Pure Python standard library: a hand-built 5x7 bitmap font, vector pictograms and a from-scratch PNG encoder. No photos, no network at run time, deterministic output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
